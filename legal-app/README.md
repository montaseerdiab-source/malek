# حقوقي — تطبيق مقتطفات قانونية مبسّطة

نموذج أولي بـ React Native (Expo) وواجهة عربية من اليمين لليسار.

## التشغيل
```
cd legal-app && npm install && npx expo start
```
ثم افتح التطبيق عبر Expo Go على الجوال.

## الحالي
بحث وتصفية حسب الموضوع والمنصة، وبطاقات منظمة (لك / عليك / صح أم خطأ / المصدر) من بيانات تجريبية في `src/data.js`، مع تنويه أنها ليست استشارة قانونية.

## الخطة
1. **المصادر**: واجهات المنصات الرسمية (X وYouTube Data API وغيرها) حسب شروطها، أو روابط يشاركها المستخدم، بدل الكشط المخالف للشروط. تفضيل المصادر الرسمية (أنظمة وقوانين منشورة).
2. **التلخيص**: خادم وسيط (`src/ai.js`) يستدعي Claude لتحويل النص إلى JSON بنفس بنية البطاقة، دون تخزين مفتاح API في التطبيق.
3. **الدقة**: تحديد الدولة، وإظهار المصدر دائمًا، ووسم "يعتمد" عند الاختلاف، ومراجعة بشرية للمحتوى الحساس.
4. **لاحقًا**: حفظ المفضلة، إشعارات، مشاركة البطاقة، تسجيل دخول.
